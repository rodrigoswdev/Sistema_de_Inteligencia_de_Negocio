# Manual de usuario

## Acceso

Ejecute `npm run dev`, abra `http://localhost:3000` e inicie sesión. En modo
demo use `admin@cbn.local` y `Password123`.

## Módulos

- Resumen ejecutivo: KPI consolidados, tendencia, semáforo y alertas.
- Ventas: venta neta, unidades, ticket, margen y detalle multidimensional.
- Finanzas: ingresos, costos, EBITDA y comparación presupuestaria.
- Desempeño: cumplimiento, ranking y unidades bajo umbral.
- Reportes: historial, formatos y programación.
- Alertas: priorización y atención de desviaciones.
- Cargas: validación de CSV/XLSX, calidad, errores y reintento.
- Administración: usuarios, roles, KPI y bitácora.

Los módulos visibles dependen del rol asignado. Los filtros no modifican datos:
solo cambian el universo analizado. Todo contenido del modo demo es simulado.
